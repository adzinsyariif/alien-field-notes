# Alien Field Notes: The Two Day Earth Review

A one-line review of planet Earth, left by an alien tourist — written by a small
deterministic Node 22 program (`main.ts`, standard library only) that writes the
line to `/output/entry.txt`.

## The entry

> Came to Earth for two days. The locals queue for fun, pay to sleep indoors, and worship a glowing rectangle they call 'work'. Great sunsets. 4/5, would orbit again.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly one line of plain text (under 200 characters) and
is fully deterministic: every run produces the same bytes.
